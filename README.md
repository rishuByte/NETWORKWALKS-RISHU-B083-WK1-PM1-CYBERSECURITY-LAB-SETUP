## 1. Project Overview
The objective of this project is to set up a basic cybersecurity lab using Oracle VM VirtualBox and Kali Linux. This virtual environment will be used for future cybersecurity and ethical hacking practice.

## 2. Objectives
- Install Oracle VM VirtualBox.
- Import and configure Kali Linux.
- Configure virtual network connectivity.
- Enable clipboard sharing and drag-and-drop.
- Configure a shared folder.
- Test internet connectivity from Kali Linux.

## 3. Tools and Technologies
| Tool | Purpose |
|---|---|
| Oracle VM VirtualBox | Virtualization platform |
| Kali Linux | Cybersecurity testing OS |
| Windows | Host operating system |
| NAT Networking | Internet connectivity |

## 4. Implementation

### Step 1: Install VirtualBox
Installed Oracle VM VirtualBox on the host machine.

### Step 2: Import Kali Linux
Imported the Kali Linux virtual machine into VirtualBox and started it successfully.

### Step 3: Configure Network
Configured the VM network adapter. NAT mode was used to establish internet connectivity.

### Step 4: Enable Integration Features
Enabled and tested clipboard sharing, drag-and-drop, and the shared folder between the host and Kali Linux.

### Step 5: Test Internet Connectivity
Tested connectivity using ping commands from Kali Linux. Internet connectivity was verified in NAT mode.

## 5. Troubleshooting
During configuration of the NAT Network, the Kali Linux VM was unable to reach the gateway. The gateway showed an unreachable response.

To continue the lab setup, the VM was switched to NAT mode. Internet connectivity was successfully tested in NAT mode.

The NAT Network gateway and the required static IP configuration still require separate verification.
